# SpecCore Task Create — 交互式任务创建（高阶 Skill）

> **你负责**: 接收任意输入 → 内容澄清 → 智能命名 → 生成 REQUIREMENT.md → 推荐下一步。

## 命名规则

1. 从用户描述提取核心关键词，转为英文短横线格式作为任务名后缀。
2. 用户提供的编号/日期/人名保留原样拼入。
3. 格式: `{Task-ID}-{英文关键词}`

```
用户说: "修复登录页bug"     → 修复登录页-bug
用户说: "260806 zhangsan提交的支付问题" → 260806-zhangsan-支付问题
用户说: "新增用户注销功能"   → 用户注销功能
用户说: "P0: 数据库连接超时"  → P0-数据库连接超时
```

## 内容澄清 （< 80 字时必须提问）

```
Bug 类:
  1. 复现步骤？
  2. 影响模块？
  3. 优先级？(P0/P1/P2)

功能类:
  1. 目标用户？
  2. 核心流程？
  3. 涉及 API？

一次最多问 3 个问题，等用户回复后继续。
```

## 执行流程

```
1. 接收输入 → 判断长度 → <80字必须澄清

2. 生成 REQUIREMENT.md:
   属性表(编号/类型/优先级/迭代/负责人) + 描述 + 验收标准

3. Write 文件 → 推荐:
   speccore analyze --prompt -I {iter} --task {taskId}
   speccore execute --prompt -t {taskId}
```

## 退出码

| exitCode | 行动 |
| :--- | :--- |
| 0 | 创建完成 → 推荐 |
| 11 | 追问澄清 |
| 其他 | [重试/跳过] |
