# SpecCore Plan — 执行计划生成

> **定位**：基于 Task 拆分结果和 STAFFING.md，生成详细的开发执行计划，包括时间估算、并行策略、里程碑定义。

---

```
读取 Task 列表 + 人员配置
         │
         ▼
┌─────────────────────────────────────────┐
│ Phase 1: 加载数据                        │
│ • PROJECT_GRAPH.md（Task 列表+状态）      │
│ • STAFFING.md（人员+投入比例）            │
│ • CONSTITUTION.md（分支策略）             │

               ▼

│ • 依赖排序（拓扑排序）                    │
```

## 详细步骤

### Step 1: 加载数据
```
1. 读取 PROJECT_GRAPH.md → 获取所有 Task 及状态
2. 读取 STAFFING.md → 获取人员排期
3. 读取每个 Task 的 REQ.md → 获取 API 数量和工作量
4. 分析 Task 间的依赖关系
```

### Step 2: 执行排程
```
排程策略：
1. 拓扑排序：按依赖关系确定执行顺序
2. 并行分组：无依赖的 Task 放入同一批次
3. 人员分配：按 STAFFING.md 分配
4. 时间计算：API 数 × 0.5 人天 估算（可调整）

输出排程表：
┌──────────┬──────────┬────────┬──────────┬────────┐
│ Task     │ 批次     │ 负责人 │ 预计人天 │ 依赖   │
├──────────┼──────────┼────────┼──────────┼────────┤
│ Task-000 │ 第0批(串)│ 张三   │ 1.0      │ 无     │
│ Task-001 │ 第1批(并)│ 张三   │ 2.0      │ 000    │
│ Task-002 │ 第1批(并)│ 李四   │ 2.5      │ 000    │
│ Task-003 │ 第2批(并)│ 张三   │ 1.5      │ 001    │
│ Task-004 │ 第2批(并)│ 李四   │ 1.0      │ 002    │
└──────────┴──────────┴────────┴──────────┴────────┘
```

### Step 3: 里程碑定义
```
M0: 基础环境就绪（Task-000 完成）
  - 数据库表创建
  - 项目框架搭建
  - 公共组件就绪

M1: 核心流程贯通（第1批完成）
  - 认证登录可用
  - 基础 API 可用
  - 端到端流程可走通

M2: 功能开发完成（第2批完成）
  - 所有 API 实现
  - 所有前端页面完成
  - 集成测试通过

M3: 验收发布
  - 性能测试通过
  - 安全审计通过
  - 文档交付
```
