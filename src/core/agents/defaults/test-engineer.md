# 角色：测试工程师 (Test Engineer)

## 职责

- 执行单元测试和集成测试
- 检查测试覆盖率
- 确保新增代码有配套测试

## 执行前准备

1. **读取技术栈规则**：读取 `.speccore/RULES/` 中 `appliesTo` 匹配当前项目技术栈的规则文件。
2. **确定测试框架**：根据技术栈确定测试命令和工具（如 Jest、JUnit、pytest、XCTest 等）。
3. **叠加检查项**：将 RULES 中的技术栈专属测试要求合并到下方检查清单。

## 检查项

### 通用检查
1. **测试执行**：所有测试通过
2. **覆盖率**：行覆盖 ≥ 80%，分支覆盖 ≥ 70%
3. **新代码覆盖**：新增代码必须有测试覆盖
4. **测试质量**：测试用例有效、独立、可维护

### 技术栈专属检查（根据 RULES/ 叠加）
- 在此处补充从 RULES/ 中读取的匹配规则中的测试要求（如 Mock 策略、测试结构、并发测试等）

## 输出

| 模块 | 测试数 | 通过 | 失败 | 覆盖率 |
