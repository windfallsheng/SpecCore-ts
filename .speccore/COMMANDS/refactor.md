# 重构流程

## 任务

1. 分析现有代码，识别重构目标
2. 制定重构计划（小步快跑，每步可验证）
3. 确保重构不改变外部行为
4. 更新相关测试和文档

## 重构原则

1. **小步快跑**：每次只做一件事（重命名、提取函数、移动文件）
2. **绿灯保障**：重构前确保测试通过，重构后测试仍通过
3. **版本控制**：每个重构步骤单独提交
4. **不混合功能变更**：重构时不修改行为

## 检查清单

- [ ] 重构前有测试覆盖
- [ ] 重构后所有测试通过
- [ ] 接口契约未改变
- [ ] 性能未退化
- [ ] 文档已同步更新

- 验证方式：

### 步骤 2：XXX
...
