# architecture — 架构模式

跨端通用的架构设计模式。涵盖项目结构、模块划分、服务拓扑、分层架构等。

## 何时沉淀

- 发现独特的项目目录组织方式
- 发现微服务/单体/模块化等架构风格
- 发现跨服务的数据流或事件驱动模式
- 发现分层架构的具体实现（Controller-Service-Repository 等）

## 示例模式

| 模式名 | 说明 |
|:---|:---|
| microservice-gateway | 微服务网关统一入口模式 |
| layered-architecture | 分层架构各层职责与依赖方向 |
| event-driven-saga | 事件驱动的分布式事务模式 |
