# 评审检查清单模板

> 本模板指导如何撰写专业的评审检查清单。
> 按端分章节撰写，覆盖安全、质量、性能、兼容性等维度。

## 写作原则

1. **逐项可检查**：每个评审项必须是明确的"通过/不通过"判定
2. **按端差异化**：后端关注安全/事务/性能，前端关注兼容/体验/性能
3. **优先级标注**：标注哪些是必须通过的（🔴），哪些是建议的（🟡）

## 文档结构

### 1. 安全评审

#### 1.1 后端安全

| # | 检查项 | 类型 | 说明 |
| :--- | :--- | :---: | :--- |
| S-01 | 接口鉴权 | 🔴 | 所有业务接口是否都有鉴权中间件 |
| S-02 | 参数校验 | 🔴 | 用户输入是否都经过校验（类型/长度/范围） |
| S-03 | SQL 注入防护 | 🔴 | 是否使用参数化查询/ORM，禁止拼接 SQL |
| S-04 | 敏感数据保护 | 🔴 | 密码是否加密存储，日志是否脱敏 |
| S-05 | 权限控制 | 🔴 | 是否实现数据级权限（不只是功能级） |
| S-06 | 接口限流 | 🟡 | 高频接口是否有频率限制 |
| S-07 | CORS 配置 | 🟡 | 跨域配置是否合理（不是 *） |
| S-08 | 日志审计 | 🟡 | 关键操作是否有日志记录 |

#### 1.2 前端安全

| # | 检查项 | 类型 | 说明 |
| :--- | :--- | :---: | :--- |
| FS-01 | XSS 防护 | 🔴 | 用户输入是否正确转义，v-html/dangerouslySetInnerHTML 是否安全 |
| FS-02 | CSRF Token | 🔴 | 表单提交是否携带 CSRF Token |
| FS-03 | Token 存储 | 🟡 | JWT/Session Token 存储方式是否安全 |
| FS-04 | 接口签名 | 🟡 | 敏感操作是否有接口签名验证 |
| FS-05 | 敏感信息泄露 | 🔴 | 前端代码/控制台是否暴露敏感信息 |

### 2. 质量评审

#### 2.1 后端质量

| # | 检查项 | 类型 | 说明 |
| :--- | :--- | :---: | :--- |
| Q-01 | 事务一致性 | 🔴 | 跨表/跨服务操作是否有事务保护 |
| Q-02 | 幂等性 | 🔴 | 重复请求是否产生重复数据 |
| Q-03 | 错误处理 | 🔴 | 异常是否统一捕获并返回规范格式 |
| Q-04 | 数据校验 | 🔴 | 前后端是否双重校验（不能只靠前端） |
| Q-05 | 并发安全 | 🟡 | 高并发场景是否有锁/乐观锁保护 |
| Q-06 | 回滚机制 | 🟡 | 失败场景是否有数据回滚/补偿 |

#### 2.2 前端质量

| # | 检查项 | 类型 | 说明 |
| :--- | :--- | :---: | :--- |
| FQ-01 | 表单校验 | 🔴 | 必填/格式/长度是否完整校验 |
| FQ-02 | 加载状态 | 🔴 | 请求中是否禁用按钮/显示 Loading |
| FQ-03 | 错误提示 | 🔴 | 接口失败是否有用户可见的错误提示 |
| FQ-04 | 防重复提交 | 🔴 | 按钮是否有防抖/禁用处理 |
| FQ-05 | 数据缓存 | 🟡 | 列表页返回时是否保持状态 |
| FQ-06 | 内存泄漏 | 🟡 | 组件卸载时是否清理定时器/订阅 |

### 3. 性能评审

#### 3.1 后端性能

| # | 检查项 | 类型 | 说明 |
| :--- | :--- | :---: | :--- |
| P-01 | 慢查询 | 🔴 | 是否有 N+1 查询/全表扫描 |
| P-02 | 索引使用 | 🔴 | 高频查询字段是否有索引 |
| P-03 | 缓存策略 | 🟡 | 热点数据是否有缓存 |
| P-04 | 批量操作 | 🟡 | 大数据量是否分批处理 |
| P-05 | 连接池 | 🟡 | 数据库/Redis 连接池配置是否合理 |

#### 3.2 前端性能

| # | 检查项 | 类型 | 说明 |
| :--- | :--- | :---: | :--- |
| FP-01 | 首屏加载 | 🔴 | 首屏关键资源是否优化（懒加载/代码分割） |
| FP-02 | 列表性能 | 🟡 | 长列表是否使用虚拟滚动 |
| FP-03 | 图片优化 | 🟡 | 图片是否压缩/懒加载/WebP |
| FP-04 | 打包体积 | 🟡 | 是否按需引入组件库 |
| FP-05 | 请求优化 | 🟡 | 是否有请求合并/缓存/预加载 |

### 4. 兼容性评审（前端专属）

| # | 检查项 | 类型 | 说明 |
| :--- | :--- | :---: | :--- |
| C-01 | 浏览器兼容 | 🔴 | 是否覆盖目标浏览器范围 |
| C-02 | 移动端适配 | 🔴 | 不同屏幕尺寸下布局是否正常 |
| C-03 | 触摸交互 | 🟡 | 触摸事件是否正确处理（vs 鼠标事件） |
| C-04 | 弱网体验 | 🟡 | 网络慢时是否有 Loading/超时处理 |

### 5. 可维护性评审

| # | 检查项 | 类型 | 说明 |
| :--- | :--- | :---: | :--- |
| M-01 | 代码规范 | 🟡 | 是否遵循项目命名/目录/注释规范 |
| M-02 | 配置分离 | 🟡 | 环境相关配置是否外置 |
| M-03 | 日志规范 | 🟡 | 日志级别是否合理，是否有敏感信息 |
| M-04 | 文档完整 | 🟡 | API 文档/README 是否更新 |
