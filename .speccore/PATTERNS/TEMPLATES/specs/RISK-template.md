## 1. 风险评估方法

### 1.1 评分标准

<!-- RPN (Risk Priority Number) = 概率(P) × 影响(I) × 检测难度(D)，每项 1-5 分，RPN 越高越需要优先处理 -->

| 维度 | 评分 | 1 | 2 | 3 | 4 | 5 |
|------|------|---|---|---|---|---|
| 概率 (P) | 发生可能性 | < 5% | 5%-15% | 15%-30% | 30%-50% | > 50% |
| 影响 (I) | 对业务/系统的影响 | 可忽略 | 轻微 | 中度 | 严重 | 灾难性 |
| 检测难度 (D) | 发现该风险的难易程度 | 极易发现 | 容易发现 | 中等 | 难以发现 | 几乎无法发现 |

### 1.2 风险等级判定

| RPN 范围 | 风险等级 | 响应策略 |
|----------|---------|---------|
| 1 - 25 | 低风险 | 接受，日常监控 |
| 26 - 50 | 中风险 | 制定缓解计划，迭代跟踪 |
| 51 - 80 | 高风险 | 需制定详细应对方案，周期性回顾 |
| 81 - 125 | 极高风险 | 必须制定应急预案，上报管理层 |

## 3. 技术风险详解

### 3.1 性能风险

#### RISK-001: 支付网关高峰期不可用

| 维度 | 说明 |
|------|------|
| **风险描述** | 大促期间（如双11、618）支付调用量暴增，微信支付网关可能限流或降级，导致用户无法完成支付 |
| **触发条件** | 瞬时 QPS 超过 5000 或支付网关 SLA 降级 |
| **影响范围** | 所有下单未支付用户，预计影响比例 15%-30% |
| **现有控制** | 暂无（当前直接调用支付 API，无本地缓冲） |
| **发生概率** | 3（每年 1-2 次大促） |
| **影响程度** | 5（核心交易链路不可用 = 收入直接损失） |
| **检测难度** | 4（支付网关超时或返回错误，但缺乏主动探测） |

#### RISK-002: 分库分表后跨库查询性能下降

| 维度 | 说明 |
|------|------|
| **风险描述** | 分库分表后，按 customer_id 以外的维度查询（如按订单号、按时间范围）需要跨库查询，性能大幅下降 |
| **触发条件** | 运营后台查询"近 7 天所有待处理退款订单" |
| **影响范围** | 运营后台查询延迟从 ms 级升至 s 级，影响运营效率 |
| **现有控制** | 已建立 ES 搜索索引作为辅助查询通道 |

### 3.2 安全风险

#### RISK-003: 支付回调接口被重放攻击

| 维度 | 说明 |
|------|------|
| **风险描述** | 攻击者截获支付成功回调请求，重放导致重复入账 |
| **触发条件** | 攻击者能获取合法回调请求并重放 |
| **影响范围** | 单笔订单可能被重复标记为已支付，造成资损 |
| **现有控制** | 已有 Nonce + 时间戳防重放机制，幂等性校验 |

### 3.3 兼容性风险

#### RISK-004: iOS 低版本兼容性问题

| 维度 | 说明 |
|------|------|
| **风险描述** | iOS 14 以下用户可能无法正常使用小程序部分功能（如地理位置选择器） |
| **触发条件** | 用户设备运行 iOS 13.x |
| **影响范围** | iOS 13.x 用户约占目标用户 2% |
| **现有控制** | 微信小程序基础库版本 >= 2.10.0 的兼容性测试 |

## 4. 业务风险详解

### 4.1 流程风险

#### RISK-007: 退款审批节点阻塞

| 维度 | 说明 |
|------|------|
| **风险描述** | 退款需要人工审批，审批人请假/未及时处理导致退款超时，引发用户投诉和平台处罚 |
| **触发条件** | 审批责任人超过 24 小时未处理退款申请 |
| **影响范围** | 日均 50 笔退款申请中的 20% 可能超时 |
| **现有控制** | 暂无自动审批机制 |

### 4.2 数据风险

#### RISK-008: 历史数据迁移不一致

| 维度 | 说明 |
|------|------|
| **风险描述** | 从旧订单系统迁移 2000 万+ 历史订单数据到新系统，可能出现数据丢失、字段映射错误 |
| **触发条件** | ETL 脚本未覆盖所有边界场景，或中途异常中断 |
| **影响范围** | 用户历史订单查询缺失或数据错误 |
| **现有控制** | 数据校验脚本（字段数、金额总和校验） |

### 4.3 法规风险

#### RISK-009: 用户隐私数据跨境合规

| 维度 | 说明 |
|------|------|
| **风险描述** | 如使用 AWS 海外节点存储数据，可能违反《个人信息保护法》数据出境规定 |
| **触发条件** | 使用非境内机房或跨境传输用户数据 |
| **影响范围** | 合规审查不通过，可能导致应用下架或罚款 |
| **现有控制** | 服务器全部部署在国内云厂商，数据不出境 |
