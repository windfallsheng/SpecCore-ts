# 前端 UI 规格模板

> 本模板指导如何撰写专业的 UI 规格文档。
> 这是前后端契约的关键桥梁 — 字段映射必须与后端 API 响应字段一一对应。
> 按端分章节撰写，每个端独立。

## 写作原则

1. **按端独立**：每个前端（admin/H5/小程序/App）单独一个章节
2. **字段可追溯**：每个页面展示的字段必须能追溯到具体的 API 响应字段
3. **状态可枚举**：所有状态值必须前后端一致

## 文档结构

### 1. 页面结构与路由

#### 1.1 {端名} 路由表

| 路由路径 | 页面名称 | 入口 | 权限 | 备注 |
| :--- | :--- | :--- | :--- | :--- |
| /list | 列表页 | 侧边栏菜单 | 登录用户 | 支持筛选/搜索 |
| /detail/:id | 详情页 | 列表点击 | 登录用户 | |
| /form | 新建/编辑表单 | 列表按钮 | 管理员 | |
| /dashboard | 仪表盘 | 首页 | 登录用户 | 数据概览 |

#### 1.2 页面层级关系

```
首页 (Dashboard)
├── 模块A
│   ├── 列表页 (/list-a)
│   ├── 详情页 (/detail-a/:id)
│   └── 表单页 (/form-a)
└── 模块B
    ├── 列表页 (/list-b)
    └── 详情页 (/detail-b/:id)
```

### 3. 字段→UI 映射（核心）

> ⚠️ 这是前后端契约的关键部分，必须与后端 API 响应字段一一对应。

#### 3.1 {页面名} 字段映射

**数据来源**: `GET /api/xxx`

| API 字段 | 类型 | 页面展示 | 展示方式 | 备注 |
| :--- | :--- | :--- | :--- | :--- |
| id | number | 不展示 | — | 用于路由跳转 |
| name | string | 名称列 | 文本 | 可点击跳转详情 |
| status | number | 状态标签 | StatusTag 组件 | 0=空闲 1=使用中 2=维护中 |
| createdAt | string | 创建时间 | dayjs 格式化 | YYYY-MM-DD HH:mm |
| amount | number | 金额 | 分→元 + ¥ 前缀 | 千分位格式化 |
| description | string | 描述 | 多行文本，超 3 行折叠 | |
| coverUrl | string | 封面图 | Image 组件 + CDN 缩略 | 200×200 裁剪 |

#### 3.2 {表单名} 字段映射

**提交接口**: `POST /api/xxx`

| 表单字段 | 类型 | API 字段 | 控件 | 校验规则 | 必填 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 名称 | string | name | Input | 2-50 字符 | ✅ |
| 类型 | number | type | Select | — | ✅ |
| 描述 | string | description | Textarea | 最多 500 字 | ❌ |
| 日期 | string | startDate | DatePicker | ≥ 今天 | ✅ |
| 图片 | string[] | coverUrls | Upload | JPG/PNG, ≤ 5MB | ❌ |

### 4. 状态枚举（前后端共享）

> ⚠️ 状态值必须与后端数据模型中的定义完全一致。

| 枚举名 | 值 | 前端展示 | 标签颜色 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| Status.IDLE | 0 | 空闲 | 🟢 绿色 | 可被预订/使用 |
| Status.IN_USE | 1 | 使用中 | 🔵 蓝色 | 正在被使用 |
| Status.MAINTENANCE | 2 | 维护中 | 🟡 黄色 | 暂时不可用 |
| Status.DISABLED | 3 | 已禁用 | 🔴 红色 | 永久不可用 |

### 5. 交互设计

#### 5.1 列表页交互

- **搜索**：输入后 300ms 防抖自动搜索
- **筛选**：多条件组合筛选，URL 参数同步
- **分页**：默认每页 20 条，支持切换
- **排序**：点击表头排序，支持升序/降序
- **批量操作**：勾选后出现批量操作栏
- **空态**：无数据时展示空状态插画 + "去创建"按钮

#### 5.2 表单页交互

- **实时校验**：失焦时校验，提交时全量校验
- **保存草稿**：自动保存到 localStorage，5 分钟过期
- **提交防抖**：提交按钮点击后立即禁用，显示 Loading
- **成功反馈**：提交成功后 Toast 提示 + 返回列表页
- **失败处理**：接口失败时保留表单数据，显示错误原因

#### 5.3 详情页交互

- **返回**：浏览器后退 / 面包屑导航
- **编辑**：右上角编辑按钮，跳转表单页
- **删除**：二次确认弹窗，输入确认文字

### 6. 响应式适配

| 端 | 断点 | 布局策略 | 特殊处理 |
| :--- | :--- | :--- | :--- |
| Admin (PC) | ≥ 1280px | 侧边栏 + 内容区 | 表格完整展示 |
| H5 (移动) | < 768px | 底部 Tab + 全屏 | 列表卡片化，表格转列表 |
| 小程序 | < 768px | 底部 Tab + 全屏 | 遵循小程序设计规范 |
| App | 自适应 | 原生导航栏 | 适配刘海屏/底部安全区 |
