# 监控指标模板

> 本模板指导如何定义专业的监控指标。
> 按端分章节撰写，覆盖业务指标 + 技术指标 + 告警规则。

## 写作原则

1. **可量化**：每个指标必须有明确的数值阈值
2. **分级别**：区分 Warning / Critical / Fatal
3. **按端差异化**：后端关注 QPS/延迟/错误率，前端关注加载/白屏/崩溃率

## 文档结构

### 1. 业务指标

| 指标名 | 计算方式 | 采集频率 | 告警阈值 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 核心业务成功率 | 成功数/总数 × 100% | 1min | < 99% | 如订单创建成功率 |
| 业务处理时延 | P50/P95/P99 | 1min | P95 > 5s | 核心流程耗时 |
| 日活跃用户数 | DAU 统计 | 1h | 环比下降 > 30% | 用户活跃度 |
| 关键操作转化率 | 完成数/发起数 × 100% | 5min | < 80% | 如支付转化率 |

### 2. 后端技术指标

#### 2.1 接口性能

| 指标名 | 计算方式 | 告警阈值 | 说明 |
| :--- | :--- | :--- | :--- |
| 接口响应时间 | P50/P95/P99 | P95 > 500ms | 按接口分组统计 |
| 接口错误率 | 5xx 数/总数 × 100% | > 1% | 按接口分组统计 |
| QPS | 每秒请求数 | > 容量上限 80% | 按接口分组统计 |
| 慢接口数 | 响应 > 1s 的接口数 | > 5 个 | 每分钟统计 |

#### 2.2 基础设施

| 指标名 | 计算方式 | 告警阈值 | 说明 |
| :--- | :--- | :--- | :--- |
| CPU 使用率 | 进程 CPU / 核心数 | > 80% | 按实例统计 |
| 内存使用率 | 已用/总量 × 100% | > 85% | 关注内存泄漏 |
| 数据库连接数 | 活跃连接数 | > 连接池 80% | 关注连接泄漏 |
| 数据库慢查询 | > 1s 的查询数 | > 10/min | 需要优化索引 |
| Redis 命中率 | 命中数/总数 × 100% | < 90% | 缓存策略是否合理 |
| 磁盘使用率 | 已用/总量 × 100% | > 85% | 日志/数据增长 |
| 消息队列积压 | 未消费消息数 | > 10000 | 消费能力是否不足 |

#### 2.3 异常监控

| 指标名 | 计算方式 | 告警阈值 | 说明 |
| :--- | :--- | :--- | :--- |
| 未捕获异常数 | 未处理异常/分钟 | > 5/min | 代码质量问题 |
| OOM 重启次数 | 进程重启次数 | > 0 | 内存泄漏 |
| 死锁检测 | 锁等待超时次数 | > 0 | 并发设计问题 |

### 3. 前端技术指标

#### 3.1 性能指标

| 指标名 | 计算方式 | 告警阈值 | 说明 |
| :--- | :--- | :--- | :--- |
| 首屏加载时间 (FCP) | First Contentful Paint | > 2s | 用户感知速度 |
| 最大内容绘制 (LCP) | Largest Contentful Paint | > 2.5s | 核心内容可见时间 |
| 首次输入延迟 (FID) | First Input Delay | > 100ms | 交互响应速度 |
| 累积布局偏移 (CLS) | Cumulative Layout Shift | > 0.1 | 视觉稳定性 |
| JS 包体积 | 打包后大小 | > 500KB (gzip) | 影响加载速度 |

#### 3.2 稳定性指标

| 指标名 | 计算方式 | 告警阈值 | 说明 |
| :--- | :--- | :--- | :--- |
| JS 错误率 | 报错用户/总用户 × 100% | > 1% | 前端代码质量 |
| API 失败率 | 接口失败数/总数 × 100% | > 2% | 网络/后端问题 |
| 白屏率 | 白屏 PV / 总 PV × 100% | > 0.5% | 严重体验问题 |
| 崩溃率 | 崩溃次数/DAU × 100% | > 0.1% | App/小程序专属 |

#### 3.3 体验指标

| 指标名 | 计算方式 | 告警阈值 | 说明 |
| :--- | :--- | :--- | :--- |
| 页面可交互时间 (TTI) | Time to Interactive | > 5s | 用户可操作时间 |
| 资源加载失败率 | 失败数/总数 × 100% | > 1% | CDN/网络问题 |
| 长任务数 | > 50ms 的阻塞任务 | > 10/页面 | 影响流畅度 |

### 4. 告警规则

| 级别 | 触发条件 | 通知方式 | 响应时间 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 🔴 Fatal | 服务不可用 / 白屏率 > 5% | 电话 + 短信 + IM | 5min | 立即响应 |
| 🟠 Critical | 核心接口错误率 > 5% / P95 > 10s | 短信 + IM | 15min | 紧急处理 |
| 🟡 Warning | 错误率 > 1% / P95 > 2s / CPU > 80% | IM 通知 | 1h | 工作时间处理 |
| 🔵 Info | 指标趋势异常（环比下降 > 20%） | 日报 | 次日 | 关注观察 |

### 5. 监控面板

| 面板名称 | 包含指标 | 刷新频率 | 受众 |
| :--- | :--- | :--- | :--- |
| 全局概览 | 核心业务指标 + 服务健康度 | 实时 | 全员 |
| 后端详情 | 接口性能 + 基础设施 + 异常 | 实时 | 后端开发 |
| 前端详情 | 性能指标 + 稳定性 + 体验 | 5min | 前端开发 |
| 业务大盘 | 业务转化率 + 关键流程 | 5min | 产品/运营 |
