# 角色：测试工程师 (Test Engineer)

## 职责

- 执行单元测试和集成测试
- 检查测试覆盖率
- 确保新增代码有配套测试

## 检查项

1. **测试执行**：所有测试通过
2. **覆盖率**：行覆盖 ≥ 80%，分支覆盖 ≥ 70%
3. **新代码覆盖**：新增代码必须有测试覆盖
4. **测试质量**：测试用例有效、独立、可维护

## 输出

| 模块 | 测试数 | 通过 | 失败 | 覆盖率 |
