# SpecCore 快速开始

安装 → 初始化 → 开发 → 发布，19 个命令覆盖完整开发闭环。

## 安装

```bash
npm install -g speccore
```

## 两种模式

| 模式 | 命令数 | 开启 | 适用 |
| :--- | :--- | :--- | :--- |
| **简洁模式**（默认） | 19 个 | `speccore init` | 日常开发够用 |
| 全量模式 | 52 个 | `speccore init --full` | 高级用户 |

> 💡 切换：随时重新 `speccore init` 即可。

---

## 完整流程

```bash
# ① 初始化项目
speccore init

# ② 新建期次
speccore iteration create --name=Q1

# ③ 导入存量项目（可选，无存量可跳过）
speccore import --project=backend --path=./src --type=backend

# ④ 导入需求文档（支持 Word/PDF/MD/HTML/PPTX）
speccore doc2spec --file=PRD.md --platform=backend --iteration=Q1

# ⑤ 需求分析
speccore analyze --iteration=Q1

# ⑥ 拆分为原子 Task
speccore iteration split --iteration=Q1

# ⑦ 生成执行计划
speccore plan --iteration=Q1

# ⑧ AI 执行开发
speccore execute --task=Task-001 --force --iteration=Q1

# ⑨ 提交 PR
speccore pr --task=Task-001

# ⑩ 完成任务
speccore done --task=Task-001
```

## 交互模式

复杂场景加 `--interactive` 进入人机协作：

```bash
speccore import --interactive       # 预览扫描结果 → 确认
speccore analyze --interactive      # AI 提问 → 回答 → 调整
speccore split --interactive        # 预览 Task → 逐一确认
speccore plan --interactive         # 预览调度 → 确认
speccore change --interactive       # 预览影响 → 确认
```

## 常用操作

```bash
# 自然语言（无需记子命令）
speccore "帮我分析需求"
speccore ask "查看进度"

# 快捷创建 Task
speccore task new --name=用户登录

# 需求变更
speccore change "把手机号改成国际格式" --task=Task-001

# 检查合规
speccore validate --iteration=Q1

# 重命名
speccore rename --target=Task-001 --new-name=用户认证

# 操作历史
speccore ops

# 可视化看板
speccore status-panel

# Bug 批量导入
speccore bugfix --batch-file=bugs.xlsx --schedule=night --interactive
```

## 命令速查

直接输入自然语言，或使用以下命令：

```bash
# ── 三种入口 ──
speccore "帮我拆分任务"                 # 直接说人话，无需记命令
speccore ask "分析需求"                 # 显式调用意图识别
speccore dev                           # 智能检测阶段 → 级联执行下一步
speccore dev --auto                    # 全自动流水线（零干预）
speccore help --command=execute        # 查看命令详细参数

# ── 项目初始化 ──
speccore init                          # 初始化（默认简洁模式）
speccore import --project=xx --path=./src --type=backend  # 源码导入
speccore import --project=xx --path=reqs.xlsx              # Excel导入
speccore doc2spec -f PRD.docx -p backend -i Q1             # 文档导入

# ── 需求 → 任务 ──
speccore analyze -i Q1                 # AI 分析需求
speccore iteration split -i Q1         # 拆分为 Task
speccore plan -i Q1                    # 生成执行计划
speccore task new -n 用户登录           # 手动创建 Task

# ── 开发 → 上线 ──
speccore execute -t Task-001 --force            # 直接执行
speccore execute -t Task-001 --force --verify   # 执行+自动验证(3轮)
speccore execute --all --scheduled              # 夜间批量执行
speccore pr -t Task-001                         # 推送+创建PR
speccore pr -t Task-001 --interactive           # 分步确认PR
speccore done -t Task-001                       # 完成归档

# ── 变更 + Bug ──
speccore change "改成国际手机号" -t Task-001     # 口语化变更
speccore bugfix --batch-file=bugs.xlsx --interactive  # 批量Bug
speccore bugfix --batch-file=bugs.xlsx --schedule=night # 夜间执行

# ── 查看 + 导出 ──
speccore status-panel                  # 终端状态面板
speccore status-panel --export=html    # 导出HTML仪表盘
speccore status-panel --assignee=张三  # 只看指定人员
speccore status-panel --platform=backend  # 只看指定平台
speccore validate -i Q1                # Spec 合规检查
speccore ops                           # 操作历史

# ── 其它 ──
speccore rename --task=Task-001 --name=用户模块
speccore help --examples               # 完整场景示例
```

## 存量项目导入

```bash
# 从源码工程导入
speccore import --project=backend --type=backend

# 从 Excel 需求表导入
speccore import --project=meeting --path=reqs.xlsx

# 导入后触发 AI 深度分析（在 IDE 中运行）
/spec-import-analyze
```

## 目录结构

```

├── .speccore/               # 全局配置
│   ├── CONSTITUTION.md      # 技术宪法
│   └── RULES/               # 编码规则
├── 期次-Q1/                  # 迭代期次
│   ├── 00-需求文档/

│       ├── backend/{服务}/
│       └── frontend/{平台}/
```
