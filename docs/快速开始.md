# SpecCore 快速开始（简洁模式）

> 📊 [总览](总览.md) | 🔧 [全量命令参考](命令参考.md) | 💡 直接输入 `speccore` 看自适应引导面板

安装 → 初始化 → 导入需求 → 分析 → 拆分 → 开发 → 发布 — 一条龙

## 安装

```bash
npm install -g speccore
```

## 两种模式

| 模式 | 命令数 | 适用 |
| :--- | :--- | :--- |
| **简洁模式**（默认） | 19 个 | 新用户，核心流程够用 |
| **全量模式** | 79+ 个 | 高级用户，精细控制 |

切换：`speccore init --full` 开启全量，`speccore init` 回到简洁

---

## 核心 7 步

```bash
# ① 初始化项目（默认简洁模式）
speccore init

# ② 导入需求（支持 Word/PDF/MD/HTML/PPTX）
speccore doc2spec --file=PRD.md --platform=backend --iteration=Q1

# ③ 分析需求
speccore analyze --iteration=Q1

# ④ 拆分为原子 Task
speccore split --iteration=Q1

# ⑤ 执行开发
speccore execute --task=Task-001 --force --iteration=Q1

# ⑥ 提交 PR
speccore pr --task=Task-001

# ⑦ 完成任务
speccore done --task=Task-001
```

## 智能辅助

```bash
# 一键级联：自动检测 → 分析 → 拆分 → 执行
speccore dev

# 可视化看板：全部 Task 进度 + 下一步建议
speccore status-panel

# 自然语言意图：不用记命令
speccore ask "分析下当前需求"
speccore ask "创建PR"
```

## 常用操作

```bash
# 新建期次（导入需求前必须先建）
speccore iteration create --name=Q2

# 查看单个 Task 详情 / 修改状态
speccore task --task=Task-001

# 生成执行计划（Task 依赖关系 + 排期）
speccore plan --iteration=Q1

# 手动创建 Task
speccore new-task --iteration=Q1 --name=用户登录

# 需求变更（中期调整）
speccore change --iteration=Q1 --type=add --desc="新增支付模块"

# 检查代码是否符合 Spec
speccore validate --iteration=Q1

# 查看操作历史
speccore ops

# 改期次/Task 名
speccore rename --target=Task-001 --new-name=用户认证
```

## CLI vs Slash Command

| 操作 | 在哪执行 | 原因 |
| :--- | :--- | :--- |
| `speccore init` | 🖥️ 终端 | 纯文件操作，AI 帮不上忙 |
| `speccore dev` | 🖥️ 终端 | 阶段检测快，不消耗 Token |
| `speccore analyze` | 🖥️ 终端 | 结构检查，终端输出最直接 |
| `speccore split` | 🖥️ 终端 | 任务拆分，定向操作 |
| `speccore execute` | 🖥️ 终端 | 代码生成，批量操作 |
| `speccore pr / done` | 🖥️ 终端 | Git 操作，不可逆转 |
| `/spec-spec "..."` | 🤖 Qcoder | 自然语言意图识别，需要 AI |
| `/spec-dashboard` | 🤖 Qcoder | AI 解读仪表盘数据 |
