# 消息通知

## 产品定位

消息通知模块负责向用户推送订单状态、系统公告与营销活动三类消息，是用户管理与订单管理之后的第三块基础能力。

## 1. 站内信通知

用户在客户端内收到站内信，支持已读/未读状态标记与一键全部已读。

- 站内信列表按时间倒序展示，未读加粗并带角标
- 点击单条消息进入详情页，自动标记为已读
- 支持按类型筛选：订单通知 / 系统公告 / 营销活动
- 未读总数在客户端底部导航栏角标实时展示

## 2. 订单状态推送

订单状态变更时，向用户推送通知并联动站内信：

- 支付成功、发货、送达三个节点触发推送
- 推送失败自动降级为站内信，不丢消息
- 用户可在设置中关闭某类订单通知

## 3. 系统公告

运营后台发布公告，全量或定向推送至指定用户群：

- 支持定时发布与撤回
- 定向推送按用户标签筛选（会员等级 / 注册时间 / 地域）
- 公告支持富文本与附件图片

## 验收标准

1. 站内信从发送到用户可见延迟不超过 3 秒
2. 订单状态推送送达率不低于 99.5%，失败自动降级站内信
3. 系统公告定时发布误差不超过 1 分钟
4. 未读角标在已读操作后 1 秒内更新
