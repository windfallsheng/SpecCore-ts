# 订单管理模块

## 功能概述

实现订单创建、查询、支付、状态流转功能。

## 功能清单

### 1. 订单创建
- 从购物车结算
- 选择收货地址
- 选择支付方式

### 2. 订单查询
- 订单列表
- 订单详情
- 订单状态筛选

### 3. 订单支付
- 微信支付
- 支付宝支付
- 支付状态回调

## 接口设计

| 方法 | 路径 | 说明 | 端 |
| :--- | :--- | :--- | :--- |
| POST | /api/v1/order/create | 创建订单 | h5, miniapp |
| GET | /api/v1/order/list | 订单列表 | h5, miniapp |
| GET | /api/v1/order/detail | 订单详情 | h5, miniapp |
| POST | /api/v1/order/pay | 订单支付 | h5, miniapp |

## 页面设计

### H5 端
- 订单确认页
- 订单列表页
- 订单详情页

### 小程序端
- 订单确认页
- 订单列表页
- 支付结果页

## 数据模型

### order 表
| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| id | BIGINT | 主键 |
| user_id | BIGINT | 用户ID |
| total_amount | DECIMAL(10,2) | 订单总金额 |
| status | TINYINT | 订单状态 |
| pay_type | TINYINT | 支付方式 |
| created_at | DATETIME | 创建时间 |
