# 用户管理模块

## 功能概述

实现用户注册、登录、个人资料管理功能。

## 功能清单

### 1. 用户注册
- 手机号注册
- 验证码验证
- 密码设置

### 2. 用户登录
- 手机号+密码登录
- 短信验证码登录
- 第三方登录（微信）

### 3. 个人资料
- 头像上传
- 昵称修改
- 手机号换绑

## 接口设计

| 方法 | 路径 | 说明 | 端 |
| :--- | :--- | :--- | :--- |
| POST | /api/v1/user/register | 用户注册 | admin, app |
| POST | /api/v1/user/login | 用户登录 | admin, app |
| GET | /api/v1/user/profile | 获取个人资料 | admin, app |
| PUT | /api/v1/user/profile | 更新个人资料 | admin, app |

## 页面设计

### Admin 端
- 用户列表页
- 用户详情页

### App 端
- 登录页
- 注册页
- 个人中心页

## 数据模型

### user 表
| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| id | BIGINT | 主键 |
| phone | VARCHAR(20) | 手机号 |
| password | VARCHAR(255) | 加密密码 |
| nickname | VARCHAR(50) | 昵称 |
| avatar | VARCHAR(500) | 头像URL |
| created_at | DATETIME | 创建时间 |
