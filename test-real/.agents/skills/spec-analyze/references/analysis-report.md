# 分析报告模板

| 报告类型 | 文件名 | 核心内容 |
| feature | ANALYSIS.md | API/数据模型/业务规则/风险 |
| bugfix | ANALYSIS.md | 根因定位/影响范围/修复方案 |
| review | REVIEW_PLAN.md | 审查范围/检查清单/关注点 |
| test | TEST_PLAN.md | 测试用例/覆盖率目标/边界测试 |
| security | SECURITY_AUDIT.md | OWASP 检查/漏洞/风险评级 |
| performance | PERF_ANALYSIS.md | 瓶颈定位/优化建议/基准 |
