# Task-001 任务CRUD - 后端需求

> 创建时间：2026-07-14
> 任务类型：feature
> 关联期次：Q3
> 关联需求：REQ-001

## 1. 需求背景

用户需要能够创建、查看、编辑、删除任务。这是任务管理系统的核心功能，后续的「任务分配」和「任务筛选」都依赖于此。

## 2. 功能描述

- **创建任务**：输入标题、描述、优先级、截止日期，创建一条新任务
- **查看列表**：分页展示所有任务，支持按优先级排序
- **查看详情**：点击任务查看完整信息
- **编辑任务**：修改标题、描述、优先级、截止日期
- **删除任务**：软删除（标记 is_deleted=true）

## 3. 接口定义

详见 `_shared/API_CONTRACT.yaml`

## 4. 验收标准

- [ ] POST /api/v1/tasks — 创建成功返回 201 + 任务 ID
- [ ] GET /api/v1/tasks?page=1&size=20 — 返回分页列表
- [ ] GET /api/v1/tasks/{id} — 返回任务详情，404 则返回错误
- [ ] PUT /api/v1/tasks/{id} — 更新成功返回 200
- [ ] DELETE /api/v1/tasks/{id} — 软删除成功返回 204
- [ ] 所有接口需参数校验（标题非空、优先级枚举值）
- [ ] 单元测试覆盖率 > 80%
