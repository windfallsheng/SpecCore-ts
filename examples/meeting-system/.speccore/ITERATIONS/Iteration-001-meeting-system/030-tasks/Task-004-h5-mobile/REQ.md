# Task-004: H5 Mobile — 需求文档

## 任务目标

开发 H5 移动端应用，为移动用户提供会议室浏览、快速预订、我的会议等功能。

## 功能范围

### 1. 用户登录
- 手机号+验证码登录
- 用户名+密码登录（备用）
- Token 管理与自动登录
- 退出登录

### 2. 会议室浏览
- 会议室卡片列表（瀑布流或纵向列表）
- 按日期、时间、容量筛选
- 会议室详情（图片轮播、设备、布局、预订情况）

### 3. 快速预订
- 引导式预订流程（选择日期 → 时间段 → 会议室 → 填写信息 → 确认）
- 可用时间可视化展示
- 会议信息填写（标题、描述、参与人）
- 提交确认

### 4. 我的会议
- 我的预订列表（Tab 切换状态）
- 会议详情查看
- 取消预订

### 5. 通知
- 系统消息推送
- 会议提醒（开始前30分钟）

## 页面清单

| 页面 | 路由 | 说明 |
|------|------|------|
| 登录页 | /login | 手机验证码/密码登录 |
| 首页 | /home | 今日概览+快速入口 |
| 会议室列表 | /rooms | 卡片列表+筛选 |
| 会议室详情 | /rooms/:id | 详情+预订入口 |
| 快速预订 | /bookings/new | 引导式预订流程 |
| 我的会议 | /my-bookings | Tab切换状态 |
| 会议详情 | /bookings/:id | 预订详情 |
| 通知中心 | /notifications | 消息列表 |

## 交付物

| 产出 | 说明 |
|------|------|
| 项目脚手架 | Vite + Vue 3 + Vant 4 |
| 路由配置 | Vue Router（移动端适配） |
| 状态管理 | Pinia Store |
| API 封装 | Axios |
| 页面组件 | 8 个页面 + 移动端适配组件 |
| 布局组件 | Tabbar 底栏 + NavBar 顶栏 |

## 非功能需求

- 移动端适配（375px - 428px 为主要目标）
- 触摸友好（按钮最小 44px）
- 首屏加载 < 3s（移动网络）
- PWA 离线支持（后续迭代）
