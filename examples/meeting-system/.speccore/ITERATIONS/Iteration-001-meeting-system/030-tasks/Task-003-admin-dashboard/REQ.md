# Task-003: Admin Dashboard — 需求文档

## 任务目标

开发后台管理面板前端应用，为管理员和用户提供可视化的会议室管理、预订管理和数据查看界面。

## 功能范围

### 1. 用户登录
- 用户名+密码登录
- Token 存储与管理
- 自动登录（记住密码）
- 退出登录

### 2. 会议室管理
- 会议室列表（分页表格，支持搜索筛选）
- 会议室详情（含设备、布局、图片）
- 新增会议室（表单 + 设备/布局动态添加）
- 编辑会议室
- 删除会议室（确认弹窗）

### 3. 预订管理
- 预订列表（分页，状态筛选）
- 预订审批（通过/拒绝 + 备注）
- 预订详情查看
- 取消预订

### 4. 数据统计
- 使用率图表（ECharts 折线图/柱状图）
- 热门时段统计
- 仪表盘概览（今日/本周数据卡片）

### 5. 布局管理
- 布局列表与增删改
- 可视化座位图预览（可选，后续迭代）

## 页面清单

| 页面 | 路由 | 说明 |
|------|------|------|
| 登录页 | /login | 登录表单 |
| 仪表盘 | /dashboard | 统计概览 |
| 会议室列表 | /rooms | 表格+筛选 |
| 会议室详情 | /rooms/:id | 详情/编辑模式 |
| 新增会议室 | /rooms/new | 创建表单 |
| 预订列表 | /bookings | 表格+筛选 |
| 预订审批 | /bookings/:id/approve | 审批对话框 |
| 通知中心 | /notifications | 消息列表 |

## 交付物

| 产出 | 说明 |
|------|------|
| 项目脚手架 | Vite + Vue 3 + TypeScript + Element Plus |
| 路由配置 | Vue Router 路由和导航守卫 |
| 状态管理 | Pinia Store（用户、会议室、预订） |
| API 封装 | Axios 拦截器 + Token 管理 |
| 页面组件 | 8 个页面 + 公共组件 |
| 布局组件 | 侧边栏 + Header + 主内容区 |

## 非功能需求

- 首屏加载 < 2s
- 支持响应式布局（1920x1080 为主，兼容 1366x768）
- 表格支持排序、分页、导出
