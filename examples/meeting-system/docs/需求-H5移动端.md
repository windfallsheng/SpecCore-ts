# H5 移动端需求

> **平台**: H5 移动端 | Vue 3 + Vant UI | 微信/浏览器  
> **原型参考**: `../prototype-h5.html`

---

## 1. 会议室浏览与搜索

员工在手机上快速浏览可用会议室。

| GET | /api/h5/rooms | 可用会议室列表（按楼层排序） |
| GET | /api/h5/rooms/:id | 会议室详情 + 今日时间轴 |

- 显示：名称、容量、设备图标、今日剩余时段数
- 支持按楼层/容量筛选
- 已满会议室灰色置底

## 2. 快速预订

选择时段后自动匹配可用会议室完成预订。

| POST | /api/h5/bookings | 创建预订（含冲突自动检测） |
| GET | /api/h5/bookings/mine | 我的预订列表 |
| DELETE | /api/h5/bookings/:id | 取消预订（开始前 30 分钟可取消） |

- 预订时自动检测时段冲突
- 预订成功推送通知
- 单人单日最多预订 4 个时段

## 3. 会议签到

扫码或手动签到，记录实际参会。

| POST | /api/h5/checkin/:bookingId | 会议签到 |
| GET | /api/h5/checkin/:bookingId | 签到状态 |

- 签到时间窗：开始前 15 分钟 ~ 开始后 30 分钟
- 超时未签到自动标记缺席
- 支持二维码扫码签到

## 4. 消息通知

预订状态变更通知。

| GET | /api/h5/notifications | 通知列表 |
| PUT | /api/h5/notifications/:id/read | 标记已读 |

- 类型：预订成功、预订取消、会议提醒、签到提醒
- 批量标记已读
- 未读红色角标
