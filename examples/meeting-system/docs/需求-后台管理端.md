# 后台管理端 — Web 管理端需求

> **平台**: Web 管理端 | Vue 3 + Element Plus | PC 浏览器  
> **原型参考**: `../prototype-admin.html`

---

## 1. 会议室管理（CRUD）

管理员对所有会议室进行增删改查管理。

| POST | /api/admin/rooms | 新增会议室 |
| GET | /api/admin/rooms | 会议室列表（分页+按楼层/容量筛选） |
| GET | /api/admin/rooms/:id | 会议室详情 |
| PUT | /api/admin/rooms/:id | 编辑会议室 |
| DELETE | /api/admin/rooms/:id | 软删除会议室 |

- 列表默认分页 10 条，支持关键字搜索
- 新增/编辑表单校验：名称必填、容量 ≥1、楼层必选
- 删除为软删除
- 设备多选：投影仪、白板、视频会议、音响、电话

## 2. 预订管理

管理员查看和管控所有预订。

| GET | /api/admin/bookings | 所有预订列表（按日期/会议室/状态筛选） |
| GET | /api/admin/bookings/:id | 预订详情 |
| DELETE | /api/admin/bookings/:id | 管理员强制取消（需填原因） |

- 列表按时间倒序
- 支持按日期范围筛选
- 取消后通知预订人

## 3. 用户权限管理（RBAC）

超级管理员管理用户和角色权限。

| POST | /api/admin/users | 新增用户 |
| GET | /api/admin/users | 用户列表（按角色/部门筛选） |
| PUT | /api/admin/users/:id | 编辑用户信息 |
| PUT | /api/admin/users/:id/role | 变更角色 |
| DELETE | /api/admin/users/:id | 禁用/启用用户 |

- 角色：super_admin / admin / user
- 禁用后不可登录和预订
- 变更角色需超级管理员权限

## 4. 数据统计看板

会议室使用率和预订趋势可视化。

| GET | /api/admin/dashboard/stats | 核心统计 |
| GET | /api/admin/dashboard/trends | 近30天趋势 |
| GET | /api/admin/dashboard/hot-rooms | 热门会议室TOP10 |

- Redis 缓存，5 分钟刷新
- 折线图 + 柱状图展示
