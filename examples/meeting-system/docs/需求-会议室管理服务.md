# 会议室管理服务 — 后台服务需求

> **服务名称**: room-service  
> **技术栈**: Spring Boot 3 + MyBatis-Plus + MySQL  
> **职责**: 会议室资源 CRUD、设备管理、楼层管理、日程查询

---

## 接口清单

| POST | /api/rooms | 新增会议室 |
| GET | /api/rooms | 会议室列表（分页+筛选） |
| GET | /api/rooms/:id | 会议室详情 |
| PUT | /api/rooms/:id | 更新会议室 |
| DELETE | /api/rooms/:id | 软删除会议室 |
| GET | /api/rooms/:id/schedule | 该会议室今日时间安排 |

---

## 数据库：rooms 表

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| id | BIGINT | 主键自增 |
| name | VARCHAR(100) | 会议室名称 |
| capacity | INT | 容纳人数 |
| floor | VARCHAR(20) | 所在楼层 |
| equipment | JSON | 设备列表 |
| status | TINYINT | 0=空闲 1=使用中 2=维护中 |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |

## 数据库：users 表

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| id | BIGINT | 主键自增 |
| name | VARCHAR(50) | 姓名 |
| email | VARCHAR(100) | 邮箱 |
| role | VARCHAR(20) | 角色 |
| status | TINYINT | 0=正常 1=禁用 |
| created_at | DATETIME | 创建时间 |

---

## 非功能要求

- 列表查询 < 200ms
- 支持 500 TPS 并发
- JWT 认证 + RBAC 权限校验
