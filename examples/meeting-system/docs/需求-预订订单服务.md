# 预订订单服务 — 后台服务需求

> **服务名称**: booking-service  
> **技术栈**: Spring Boot 3 + MyBatis-Plus + MySQL + Redis  
> **职责**: 预订订单管理、冲突检测、会议签到、消息通知

---

## 接口清单

| POST | /api/bookings | 创建预订（含冲突检测） |
| GET | /api/bookings | 预订列表 |
| GET | /api/bookings/:id | 预订详情 |
| DELETE | /api/bookings/:id | 取消预订 |
| POST | /api/bookings/check-conflict | 检查时段冲突 |
| POST | /api/checkin/:bookingId | 会议签到 |
| GET | /api/notifications | 通知列表 |

---

## 冲突检测规则

- 同一会议室同一时段不允许重复预订
- 检测精度：分钟级
- 查询条件：start_time < 请求结束时间 AND end_time > 请求开始时间

## 业务规则

- 单人单日最多预订 4 个时段
- 会议开始前 30 分钟内不可取消
- 签到时间窗：开始前 15 分钟 ~ 开始后 30 分钟
- 超时未签到自动标记缺席

---

## 数据库：bookings 表

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| id | BIGINT | 主键自增 |
| room_id | BIGINT | 会议室ID |
| user_id | BIGINT | 预订人ID |
| title | VARCHAR(200) | 会议主题 |
| start_time | DATETIME | 开始时间 |
| end_time | DATETIME | 结束时间 |
| status | TINYINT | 0=已确认 1=进行中 2=已完成 3=已取消 4=缺席 |
| cancel_reason | VARCHAR(500) | 取消原因 |
| checkin_at | DATETIME | 签到时间 |
| created_at | DATETIME | 创建时间 |

## 数据库：notifications 表

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| id | BIGINT | 主键自增 |
| user_id | BIGINT | 用户ID |
| type | VARCHAR(20) | 通知类型 |
| title | VARCHAR(200) | 通知标题 |
| content | TEXT | 通知内容 |
| is_read | TINYINT | 0=未读 1=已读 |
| created_at | DATETIME | 创建时间 |

---

## 非功能要求

- 冲突检测 < 500ms
- 500 TPS 并发
- Redis 缓存会议室实时状态
- 敏感操作记录审计日志
