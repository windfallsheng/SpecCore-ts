# frontend-h5需求

> 来源: `docs/需求-H5移动端.md` | 原型: `prototype-h5.html`

**平台**: 移动端 H5 | 框架: Vue 3 + Vant 4 + Vite

## 页面清单

| 页面 | 路由 | 路径 | 用途 | 优先级 |
| :--- | :--- | :--- | :--- | :--- |
| 会议室列表 | `/` | views/Home.vue | 日期选择 + 会议室卡片 | P0 |
| 预订确认 | `/book/:roomId` | views/Book.vue | 时间段选择 + 提交 | P0 |
| 我的预订 | `/my` | views/MyBookings.vue | 预订列表 + 取消 | P0 |

## 会议室列表页

- 顶部日期选择器（仅未来 7 天可选，过去日期灰掉）
- 会议室卡片列表，每张卡片显示:
  - 名称（大字号）· 楼层 · 容量 · 设备（图标，3 个以内直接展示，超过显示"+N"）
  - 当前时段占用状态: 🟢 空闲 / 🔴 占用中
- 下拉刷新
- 点击卡片 → 跳转预订页

## 预订确认页

- 顶部: 选中会议室信息摘要
- 时间段选择: 30 分钟粒度，09:00-18:00，已占用时间段灰掉不可选
- **实时冲突检测**: 选择时间段后自动调 `/api/v1/bookings/check-conflict`
  - 冲突: 按钮变红、显示"该时段已被预订"、提交按钮禁用
  - 无冲突: 按钮变蓝、可提交
- 表单: 会议主题(必填) / 参会人员(选填,拼接)
- 提交: loading → 成功 → 跳转 /my → toast "预订成功"
- 失败: toast 错误信息

## 我的预订页

- 列表: 会议主题/日期/时间段/状态标签
- 左滑操作: 查看详情 / 取消（确认弹窗）
- 空状态: 插画 + "暂无预订"
- 状态: 有效(蓝色) / 已取消(灰色) / 已完成(绿色)

## 非功能要求

| 类别 | 要求 |
| :--- | :--- |
| 适配 | 375px ~ 414px（iPhone SE ~ iPhone 15 Pro Max） |
| 微信 | 微信内置浏览器兼容 |
| 性能 | 首屏 < 1.5s |
| PWA | 支持添加到桌面（可选 P1） |
