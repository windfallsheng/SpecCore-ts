# 错误码定义: Task-002 预订订单服务

| 错误码 | HTTP | 含义 | 返回示例 |
| :--- | :--- | :--- | :--- |
| 2001 | 409 | 预订时间冲突 | `{ code:2001, message:"该时段已被预订: 09:00-10:00 周会" } ` |
| 2002 | 404 | 预订不存在 | `{ code:2002, message:"预订不存在" } ` |
| 2003 | 400 | 不可预订过去时间 | `{ code:2003, message:"不可预订过去时间" } ` |

## 错误码区间
- 2000-2999: 预订订单模块
- 复用的全局码: 4001(参数校验)、5000(系统异常)
- 复用的会议室码: 1001(会议室不存在)

## 全局异常映射
```java
BookingConflictException(2001)     → 409
BookingNotFoundException(2002)     → 404  
PastDateException(2003)           → 400
```
