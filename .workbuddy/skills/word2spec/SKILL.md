# Word → SpecCore Markdown 高级转换器

## 前置条件

- macOS + pandoc >= 3.x (`/usr/local/bin/pandoc`)
- 当前工作目录是已初始化的 SpecCore 项目（存在 `.speccore/`）

## 工作流

### 第 1 步 — 定位文件

询问用户：
1. Word 文件在哪个路径？
2. 对应哪个期次？（如 `Q3`）
3. 有哪些端的文档？（后台 / Web / 小程序 / H5）

### 第 2 步 — 转换（核心）

对每个 `.docx` 文件执行：

```bash
LANG=zh_CN.UTF-8 pandoc "源路径" \
  -f docx \
  -t gfm \
  --wrap=none \
  --extract-media="期次-${迭代名}/00-需求文档/images" \
  -o "期次-${迭代名}/00-需求文档/${端名}需求.md"
```

| 参数 | 说明 |
| :--- | :--- |
| `LANG=zh_CN.UTF-8` | 中文编码不丢失 |
| `-t gfm` | GitHub-Flavored Markdown（兼容性最强） |
| `--wrap=none` | 不硬换行 |
| `--extract-media` | 图片提取到期次目录下 |

### 第 3 步 — 后处理

转换完成后自动执行以下后处理：

#### 3.1 标题层级规范化
```bash
# Word 中 H2 变 H3，保持在 Spec 中的合理层级
sed -i '' 's/^## /### /g' "目标文件"
```

#### 3.2 接口表格标准化
如果检测到接口表格（含 `方法 | 路径 |` 列头），不做改动。
如果没有接口表格，在文件末尾追加提示：
```markdown
---
> ⚠️ 本文件从 Word 自动转换。请在下方补充接口定义表格后运行 speccore execute：

| 方法 | 路径 | 说明 |
| :--- | :--- | :--- |
| | | |
```

#### 3.3 空行清理
```bash
# 删除连续 3 个以上空行
perl -i -0pe 's/\n{3,}/\n\n/g' "目标文件"
```

#### 3.4 生成汇总索引
在 `00-需求文档/` 下自动创建/更新 `INDEX.md`：
```markdown
# 本期需求文档索引

| 端 | 文件 | 转换时间 | 来源 |
| :--- | :--- | :--- | :--- |
| 后台 | 后台需求.md | 2026-07-21 | xxx.docx |
| Web | Web前端需求.md | 2026-07-21 | yyy.docx |
```

### 第 4 步 — 多端批量处理

如果用户提供多个 Word 文件，全部转换后输出汇总：

| 端 | 输入 | 输出 | 大小 | 警告 |
| :--- | :--- | :--- | :--- | :--- |
| 后台 | api-prd.docx | 后台需求.md | 12KB | ✅ |
| Web | web-prd.docx | Web前端需求.md | 45KB | ⚠️ 含 8 张图片，已提取到 images/ |

### 第 5 步 — 提示下一步

转换完成后输出：

```
✅ 3 个文档已转换并放入 期次-Q3/00-需求文档/

📋 下一步:
   1. 检查自动转换的标题是否合理
   2. 在每份需求文档中补充「接口定义」章节的接口表格
   3. 运行: speccore iteration split
   4. 运行: speccore execute --task=Task-001 --force
```

## 图片处理规则

| 图片类型 | 处理 |
| :--- | :--- |
| 嵌入图 | pandoc 自动提取到 `images/`，路径相对引用 |
| 外部链接 | 保持原 URL 不变 |
| 架构图 | 不修改，提示用户确认引用路径 |

## 表格保留规则

| 表格内容 | 处理 |
| :--- | :--- |
| 普通文本表格 | ✅ 完整保留为 Markdown |
| 合并单元格表格 | ⚠️ MD 不支持合并单元格，降级为普通表格并标注 |
| 纯数字表格 | ✅ 保留格式 |

## 常见问题

| 现象 | 处理 |
| :--- | :--- |
| 中文乱码 | 确保 `LANG=zh_CN.UTF-8` |
| 图片不显示 | 检查 `images/` 目录和引用路径 |
| 表格错位 | MD 中手动调整列数 |
| 编号列表错乱 | pandoc 自动修复，手动复核 |
