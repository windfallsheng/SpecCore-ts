## 第四轮: Prompt 架构落地 — CLI + AI 协作循环

### 核心理念
CLI 不做代码生成，只做确定性操作(读Spec/写文件/更新状态)。
代码生成完全由宿主 AI 通过 Skill 协作完成。

### 新增 src/core/prompt-builder.ts
- buildPrompt(command, options): 读取 CONSTITUTION + REQ.md → 构建结构化 Prompt
- formatPrompt(): 序列化为 Markdown 输出到 stdout
- parseAiResponse(): 解析 AI 返回的 JSON(文件列表)
- 支持 execute/analyze/split/plan 四种 Prompt 类型

### execute.ts 改造
- --prompt 模式: 输出 [SPECCORE_PROMPT] ... [/SPECCORE_PROMPT] 到 stdout，退出码 10
- --response 模式: 接收 AI 返回内容({"files":[...]})，写入文件，更新 PROJECT_GRAPH 状态
- 保留原有模板生成逻辑(向后兼容)

### Skill 更新
- spec-execute Skill 重写: 四阶段流程(Skill→CLI→AI→CLI)替代旧模板生成描述

### 协作循环
```
Skill: execute_command("speccore execute --prompt -t Task-001")
  → CLI 输出 Prompt 到 stdout
Skill: 捕获 stdout → 传给宿主 AI
  → AI 生成代码 {"files": [...]}
Skill: execute_command("speccore execute --response '{json}' -t Task-001")
  → CLI 写入文件，更新状态
```
