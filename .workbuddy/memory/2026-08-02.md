## analyze 命令扩展 (v5.22.0)

将 `analyze` 命令从单纯的「需求分析」扩展为统一的「需求+代码分析引擎」，支持三种输入模式和三种输出范围。

### 新增文件
- `src/core/analyze-engine.ts` (~1100行) — 统一分析引擎，包含:
  - `runAnalysis()` 主入口，自动判别分析类型
  - `analyzeRequirements()` — 纯需求分析（完整性扫描+架构影响检测）
  - `analyzeCodebase()` — 纯代码分析（文件统计+API清单+复杂度热点+依赖分析）
  - `analyzeCombined()` — 联合分析（需求-代码对标+架构影响）
  - 每种分析按 scope 生成不同格式报告:
    - `global` → `.speccore/GLOBAL/` (代码健康/全局架构)
    - `iteration` → `期次-XX/00-需求文档/` (期次分析)
    - `task` → `期次-XX/Task-NN/` (任务深化+文档补全)

### 修改文件
- `src/commands/analyze.ts` — 重构为瘦 command，编排调用 engine
  - 新增 `parseArgv()` 函数手动解析 process.argv（Commander.js 偶发丢失部分选项的 workaround）
  - 折叠 `perTaskAnalyze` → `enrichTaskDocs()`
- `src/cli.ts` — 更新 analyze 命令注册，新增选项:
  - `--src`, `--req` (逗号分隔多值)
  - `--scope global|iteration|task`
  - `--depth quick|normal|deep`
  - 重命名 `--interactive` → `--ask`（避免与 `--iteration` 的 `-i` 冲突）

### 代码分析能力
- 语言统计（TS/JS/Python/Java/Go 等）
- 目录分布统计
- API 接口清单（从注解/路由自动提取）
- 复杂度热点（>800行=high, >400行=medium, TODO/FIXME/深层嵌套）
- 依赖分析（import 关系+循环依赖检测+入口点识别）
- 最大文件 TOP 10

### CLI 示例
```bash
speccore analyze --depth deep --scope global
speccore analyze --src backend/src,frontend/src --req docs/req.md --scope iteration -i Sprint-1
speccore analyze --src src/routes/order.ts --scope task -t 01 -i Sprint-1
```
