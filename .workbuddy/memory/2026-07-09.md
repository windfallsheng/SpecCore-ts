# 2026-07-09 工作日志

## SpecCore v4.0.0 — 从源项目移植最新变更

### 背景
根据 SpecCore 源项目 v4.0.0 的变更，将多平台任务管理、动态平台添加、上下文查看、索引更新等功能移植到 ts-cli。

### 新增命令（4个）

1. **`new-task`** (`nt`) — 多平台原子任务创建
   - 支持 `--platforms=web,h5,miniapp` 或 `all`
   - 支持 `--backend-only` / `--frontend-only`
   - 自动推断任务类型（feature/bugfix/research/...）
   - 目录结构：`_shared/` + `backend/` + `frontend/{platform}/`

2. **`platform-add`** (`padd`) — 动态添加前端平台
   - 更新 platforms.yaml 配置
   - 自动同步到所有现有 Task（创建 frontend/{platform}/ 骨架）

3. **`context`** (`ctx`) — 查看 Task 上下文
   - 显示 Spec 文件加载状态（按类型和平台分类）
   - 平台覆盖和跨平台依赖分析
   - 验收标准统计

4. **`index-update`** (`iu`) — 扫描重建全量索引
   - 遍历 GLOBAL/PROJECTS/ 下所有需求
   - 重建 GLOBAL/INDEX.md（--dry-run 预览模式）

### 增强命令

1. **`execute`** — 新增 `--platform=<name>` 按前端平台过滤
2. **`progress`** — 新增 `--platform=<name>` 按平台统计
3. **`import`** — 新增 `--scope=<all|core|api>`、`--ignore=<packages>`、`--update` 增量同步

### 新增配置

- `init` 命令新增 `createConfigFiles()` 函数
- `.speccore/config/platforms.yaml` — 多平台配置（web/h5/miniapp 默认启用）
