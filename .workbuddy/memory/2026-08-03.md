# 2026-08-03 工作日志

## status-panel HTML 导出 — 模板字符串转义修复

**问题**：`src/commands/status-panel.ts` 中嵌套模板字符串（`` `${...}` ``）的转义被 TypeScript 编译器错误解析，导致生成的 HTML 中健康度评分和任务生命周期部分显示为原始模板语法（如 `${data.health.donePct}%`）。

**修复**：将健康度（health）和生命周期（lifecycle）两个 HTML 注入块从嵌套模板字符串改为**数组拼接**方式（`[...].join('')`），彻底消除转义问题。同时使用 `data-i18n` 属性替代 I18N 对象引用以支持中/EN 语言切换。

**结果**：编译通过，生成的 `speccore-status.html` 正确显示：
- 🏥 健康度评分（完成率/测试覆盖/审查覆盖/综合评分）
- 📋 任务生命周期表格（8 个任务状态）
- 🌐 中/EN 语言切换正常

- **重命名**：额外传入 `excludeName` 参数排除自身，仅检查与其他名称的冲突
- **提示**：冲突时给出具体建议（如 `"name-2"` 或 `"name-补充"`）
