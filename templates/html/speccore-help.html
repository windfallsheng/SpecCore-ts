🎯 SpecCore — SDD 开发方法论 CLI 工具
SpecCore 采用 Specification-Driven Development（规格驱动开发）方法论，通过标准化流程和 AI 辅助，实现从需求到交付的自动化流水线。
💡
核心原则
  • 规格先行：先写规格文档，再执行代码
  • AI 协同：自然语言交互，智能意图识别
  • 迭代管理：任务拆分、计划、执行、审查闭环
  • 多端适配：后端 / Web / H5 / 小程序全栈支持

📋 核心参数速查
参数
含义
示例
-i, -I
迭代短名（不带 Iteration- 前缀）
-i Q1 / -I my-project
-t
任务 ID（Task-001 / Task-002 ...）
-t Task-001
-n
名称（迭代名/任务名/项目名）
-n Q1 / -n 用户登录
--prompt
AI 交互模式（需要宿主 AI）
analyze --prompt
--auto
自动模式（跳过交互确认）
execute --auto
--platforms
多端平台（逗号分隔：web,h5,miniapp）
--platforms=web,h5
--type
任务类型（feature/bugfix/refactor/research）
--type feature
--force
强制覆盖（init/update/import）
init --force
💡 使用技巧
🎯
优先使用 ask
不确定用哪个命令？直接说人话：
speccore ask "我想创建一个登录功能"
🔍
搜索命令
忘记命令名？用搜索：
speccore help --search=导入
📖
查看详细参数
了解命令用法：
speccore help --command=execute
🌐
HTML 帮助页
在浏览器中查看：
speccore help > outputs/speccore-help.html
