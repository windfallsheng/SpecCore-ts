📋 示例：/spec-ask "本期迭代：从 PRD 导入到代码提交，跑完整开发流程"
1.
speccore doc2spec -f PRD.docx --iter {iteration}
导入 PRD 文档，AI 分析生成需求规格说明书
2.
speccore analyze --iteration {iteration} --audit
AI 深度分析需求，生成审计报告和可行性评估
3.
speccore split -f REQUIREMENT.md
将需求拆分为独立开发任务，确定优先级和依赖关系
4.
speccore execute --auto
按任务计划依次自动执行开发、测试和代码生成
5.
speccore pr --auto
代码提交后自动创建 Pull Request，完成交付
